# Velvet Thorn

가시 궁정의 음모를 퍼즐로 헤쳐 나가는 다크 판타지 **매치3 RPG** (웹 프로토타입).
18+ 암시적 분위기, **노골적 묘사 없음**. [CONTENT_GUIDELINES.md](CONTENT_GUIDELINES.md) 참고.

## 실행
`index.html`을 더블클릭하세요(서버 필요 없음). 아무 곳이나 한 번 클릭하면 음악이 시작돼요.
갤러리 해금과 기록은 브라우저 localStorage에 저장돼요.
진행 중인 여정도 화면이 바뀔 때마다 자동 저장돼요(`vt_run`). 앱을 닫았다 열면 타이틀의 **이어하기**로 돌아와요. 결투 중 ❚❚ 버튼이나 앱 전환 시 일시정지돼요. 쓰러지면 저장이 지워져요.

## 언어 (한국어 / English)
- 처음 실행하면 기기 언어를 따라가요(한국어 기기 → 한국어, 그 밖 → 영어). 타이틀의 **🌐 버튼**으로 바꿀 수 있고, 선택은 저장돼요.
- 화면 문구는 `js/lang/ko.js`, `js/lang/en.js`의 `ui`에 있어요. 이야기·적·축복·컷신 문장은 `js/data.js`가 한국어 원본이고, `en.js`의 `content`가 같은 모양으로 덮어써요.
- 새 언어 추가: `js/lang/en.js`를 복사해 `js/lang/<코드>.js`로 번역하고 `index.html`에 스크립트 한 줄, `js/i18n.js`의 `LANGS`에 코드를 추가하세요.
- 이야기 문장을 바꾸면 `en.js`의 번역도 같이 고치세요.

## 규칙 (30초 요약)
- **이웃한 타일 두 개**를 바꿔 같은 그림 **3개 이상**을 한 줄로 맞추세요. 누르고 옆을 누르거나, 끌어서 놓으면 돼요.
- 🗡 **칼날** = 피해 · 🌹 **장미** = 보호막 · 🍷 **포도주** = 회복 · 🎭 **가면** = 필살기 게이지
- 🛡 보호막은 적의 다음 공격을 막고, **적이 행동하면 사라져요.**
- 적은 화면에 표시된 **"N턴 후"**에 예고한 행동을 해요.
- **5개 이상** 맞추면 한 번 더 움직여요. 연쇄로 터지면 효과가 ×1.5, ×2…로 커져요.
- 🎭 게이지가 가득 차면 **필살기**: 큰 피해를 주고 가시를 모두 없애요(턴 소모 없음).
- 🥀 **가시**는 움직일 수 없고, 바로 옆에서 맞추면 사라져요.
- 맞춰지지 않는 자리 바꾸기는 되돌아가고 턴도 쓰지 않아요. 5초 동안 가만히 있으면 힌트가 반짝여요.

## 진행 구조
- **3장, 17관문**을 정해진 순서로 지나요: 결투 → 이야기 → 결투 → 이야기 → 보스 (2장·3장은 보스 앞 휴식 포함).
- 결투에서 이기면 **축복 3개 중 1개**를 골라요(칼날 강화, 최대 체력 증가 등). 축복은 여정이 끝날 때까지 유지돼요.
- 이야기 장면에서는 선택에 따라 회복, 축복, 갤러리 장면을 얻어요.
- 체력은 결투 사이에 이어져요. 쓰러지면 단계마다 한 번 광고를 보고 그 결투를 체력 절반으로 이어갈 수 있고, 아니면 처음부터 다시 시작해요.
- **난이도 단계**: 17관문을 **초급 → 중급 → 고급** 순서로 한 번씩 지나요(축복은 이어져요). 고급 보스를 쓰러뜨리면 엔딩이 나오고, 이후 **왕좌 도전 1, 2, 3…**이 끝없이 이어져요. 최고 기록은 지금까지 통과한 관문 수예요.

## 컷신
- 프롤로그, 장 시작, 이야기 장면 6개, 포도주 저장고, 보스·강적 등장 4개, 엔딩, 패배까지 **컷신 17개**가 있어요.
- 영상 파일이 없으면 기본 시네마틱이 재생돼요: 레터박스, 타이틀 카드, 크로스페이드, 카메라 이동, 장면별 파티클(비와 번개, 꽃잎, 재, 독안개, 불씨, 금빛 반짝임, 먼지).
- 장면마다 앞쪽 레이어(커튼, 덩굴, 기둥, 촛불, 창살)가 더 빨리 움직여 깊이감이 생기고, 촛불 깜빡임과 색감(따뜻함, 차가움, 독안개 초록, 핏빛)이 들어가요.
- 자막은 한 글자씩 써지고, 대사에는 말하는 사람 이름표가 붙어요. 장면에 맞춰 천둥, 성문, 칼 뽑는 소리, 잔 따르는 소리, 종, 심장 소리가 나고, 번쩍임이나 흔들림이 들어가요.
- 보스와 강적 등장은 마지막에 이름 카드가 쾅 하고 박혀요. 컷신마다 어울리는 음악이 나와요.
- 장면 설정은 `js/data.js`의 `ASSETS.videos`에 있어요(fx, mus, grade, boss, beats의 who, fg, sfx, flash, shake). 장면을 더하면 `en.js`에도 같은 순서로 문장을 넣어 주세요.
- 컷신은 초급에서만 나오고, 중급부터는 바로 진행돼요. 엔딩 컷신은 고급을 깼을 때 나와요. 화면을 클릭하면 다음 장면으로, "건너뛰기"를 누르면 바로 끝나요.

## 밸런스 메모 (2026-10-24, 난이도 단계 도입)
`node tools/balance-bot.js 10 smart|random`로 측정했어요(헤드리스, 표본이 작고 판마다 편차가 커요).
| 봇 | 초급 클리어 | 중급 | 고급 | 왕좌 도전 1 |
|---|---|---|---|---|
| 무작위로 두는 봇 (초보 대용) | 40판 중 30판 | 거의 못 깸 | - | - |
| 효과가 큰 수를 고르는 봇 (숙련자 대용) | 30판 중 29판 | 약 절반 | 약 4분의 1 | 30판 중 5판 |

초급 측정은 지금 수치(체력 ×0.7)이고, 숙련자 봇 측정은 초급 ×0.8일 때예요. 사람이 실제로 해 본 체감 난이도는 **미확인**이에요. 수치는 `js/data.js`의 `TIERS`(단계별 적 체력·공격 배율), `THRONE_HP`, `THRONE_ATK`, `ENEMIES`, `SUITS[].base`, `GAUGE_MAX`, `FINISHER_DMG`에서 조정해요.

## 그림
- 초상화 11장과 장면 9장은 `js/art.js`에 SVG 코드로 그려져 있어요(촛불 역광 실루엣 + 금색 장식). 모든 인물은 성인이고 옷을 갖춰 입었어요.
- 보드 타일은 `js/icons.js`의 `TILE_ART`(색 채운 보석 타일), 작은 아이콘은 같은 파일의 `ICONS`(선 아이콘)예요.
- `assets/img/<id>.webp|png|jpg` 파일을 넣으면 그 파일이 코드 그림보다 우선해요.

## AI 에셋 파이프라인 (수동 생성)
1. 게임에서 **타이틀 → AI 에셋 프롬프트**를 열면 이미지 20장, 음악 5곡, 영상 17개의 프롬프트와 저장 경로가 나와요(복사, JSON 내려받기 가능).
2. 사용하는 도구로 생성해 저장하세요.
   - 이미지 → `assets/img/<id>.webp` (또는 `.png`/`.jpg`), **3:4 세로**
   - 음악 → `assets/music/<id>.mp3`, 반복 가능한 연주곡
   - 영상 → `assets/video/<id>.mp4`, 16:9, 6~10초
3. 새로고침하면 **있는 파일이 임시 그림을 자동으로 대체**해요. 파일이 없으면 SVG 임시 그림, WebAudio 신스 음악, 슬라이드쇼 영상이 대신 나와요.

일관성 팁:
- 캐릭터마다 초상화를 먼저 만들고, 그 **참조 이미지**를 모든 장면에 쓰세요.
- 영상은 같은 장면 이미지에서 image-to-video로 만드는 게 가장 일관돼요.
- 모든 프롬프트에는 공통 `STYLE` 상수(`js/data.js`, "adult", "fully clothed" 포함)가 붙어요. `NEGATIVE_PROMPT`는 도구의 **네거티브 프롬프트 칸**에 넣으세요. **둘 다 지우지 마세요.**
- 프롬프트가 안전한 결과를 **보장하지는 않아요.** 모든 결과물은 사람이 확인해야 해요.
- 쓰기 전에 CONTENT_GUIDELINES.md §4 체크리스트를 확인하세요.

## 파일 구성
```
index.html          앱 껍데기
style.css           스타일 (다크 궁정 테마, 모바일 대응)
js/data.js          타일, 적, 장 구성, 축복, 이야기, AI 에셋 프롬프트 (데이터 단일 출처)
js/media.js         에셋 로딩 + 임시 그림 / 신스 음악 / 컷신 엔진(파티클 포함)
js/config.js        앱 설정: AdMob 광고 ID(지금은 구글 테스트 ID), 광고 제거 상품 ID
js/ads.js           하단 배너 + 부활 보상형 광고 (앱: AdMob, 브라우저: 테스트용 대체 화면)
js/shop.js          광고 제거 $1.99 구매 + 구매 복원 (앱: 스토어 결제, 브라우저: 테스트 구매)
js/game.js          게임 로직 (진행, 매치3 결투, 보상, 이야기, 갤러리)
assets/             AI 생성 파일을 넣는 곳
BUSINESS_PLAN.md    글로벌 수익·출시 전략
CONTENT_GUIDELINES.md  모든 업데이트에 적용되는 콘텐츠 규칙
```

## 확장하기
- 새 적: `ENEMIES`에 추가하세요. `every`(몇 수마다 행동)와 `actions`(atk / thorn / guard / heal)만 정하면 돼요.
- 장 구성: `CHAPTERS[].nodes`에 `duel` / `event` / `rest`를 원하는 순서로 넣으세요.
- 새 축복: `BLESSINGS`에 추가한 뒤 효과를 `game.js`의 `perTile` / `applyBlessing`에 연결하세요.
- 새 이야기: `EVENTS`에 추가하고 **콘텐츠 가이드라인을 확인하세요.**
